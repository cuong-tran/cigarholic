# ADR 0002: URL structure

Status: accepted, 2026-10-30. Feature IDs: SEO-03, SHO-02, CNT-06.

## Context

URLs must be fixed before the first product is entered; changing them later costs rankings and redirects. The owner wants the option of a Shopify storefront kept open at zero runtime cost (ADR 0005).

## Decision

- Products: `/products/<slug>/` (WooCommerce product base `products`, no shop base, no category in the path).
- Categories: `/collections/<slug>/` with flat, unique slugs (no nesting in the URL even when the category tree is nested in admin).
- Journal (blog): `/journal/<slug>/`; the posts page is `/journal/`.
- Shop page: `/shop/`; cart, checkout and account keep WooCommerce defaults (`/cart/`, `/checkout/`, `/my-account/`).
- Canonical host is the apex `cigarholic.com`; `www.cigarholic.com`, `max2lab.com` and `www.max2lab.com` 301 to it with path and query preserved, one hop.

Applied by `provision/` (permalink structure `/%postname%/`, WooCommerce permalink option) and verified by the Playwright redirect tests.

## Consequences

- Shopify-compatible paths (`/products/`, `/collections/`), so a CSV export (SHO-02) can stand up a storefront with the same URLs.
- Category slugs must be unique across the whole tree; `wp cigarholic catalog:check` flags duplicates.
- Any later change is an ADR plus a redirect map in SEOPress (SEO-07).
