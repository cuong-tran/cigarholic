# History

The dated record of the build. These files only grow; the current state is `docs/STATUS.md`.

| File | Holds | Add to it |
|---|---|---|
| `merged-prs.md` | Every PR merged to `main`, with its feature IDs | At the end of each session |
| `server-runs.md` | Every workflow run that touched the VPS and its result; incidents | After each server run or deploy you read |
| `test-log.md` | What was executed in each session and what it showed, newest first | At the end of each session |
| `environment-report.md` | The sandbox as measured on 2026-10-30 and 31 | Never; the living version is `docs/runbooks/sandbox.md` |

What each release contains for users is in `CHANGELOG.md`.
